      What to upload ↗

      Choose a folder on this computer. Files are uploaded to the Workbench host.

      Upload extracted folders, up to 64 GiB. Large files transfer in chunks. Keep this page open until the upload completes.

      From Hugging Face

      The Workbench host downloads the repository directly. Private and gated repositories use the token saved on the host with hf auth login; this page never asks for it. Starting the same repository again resumes an interrupted download.

      Files already on the Workbench host

      Start Workbench with --models /path/to/checkpoints. Dataset paths can be entered on the Compile page. These paths refer to the host running Workbench.
